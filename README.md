# Handwritten Digit Recognizer Using CNN

## Overview
This project uses a Convolutional Neural Network (CNN)
to recognize handwritten digits from 0 to 9.

## Dataset
MNIST handwritten digit dataset, loaded using TensorFlow.

## Technologies
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib

## Method
1. Load and normalize the MNIST dataset.
2. Build a CNN model.
3. Train the model on handwritten digit images.
4. Evaluate the model on test data.
5. Predict a digit from a sample image.

## How to Run
Open the notebook in Google Colab and run the cells.
